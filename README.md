# PoligonoApp — Landing Page

Landing page da PoligonoApp: a plataforma que transforma empreendimentos em experiências de venda para corretores e incorporadoras.

## Paleta

- Laranja: `#FF6A00`
- Preto: `#121212`
- Cinza: `#F5F5F5`
- Branco: `#FFFFFF`

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
